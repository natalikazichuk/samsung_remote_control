# Пульт для Samsung (Android, Kotlin)

## Установка
1. Android Studio → New Project → **Empty Activity** (Compose), package `com.example.samsungremote`.
2. Замените `MainActivity.kt` и добавьте `SamsungRemote.kt` в ту же папку пакета.
3. В `app/build.gradle.kts` добавьте зависимость:
   ```
   implementation("com.squareup.okhttp3:okhttp:4.12.0")
   ```
4. В `AndroidManifest.xml` перед `<application>`:
   ```xml
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-permission android:name="android.permission.VIBRATE" />
   ```
5. Запустите на телефоне, который в той же Wi-Fi сети, что и ТВ.

## Использование
### Автопоиск ТВ
- **Поиск Wi-Fi** — ищет телевизоры Samsung в вашей сети (SSDP + проверка подсети по порту 8001). Нажмите на найденный ТВ — приложение подключится, IP вводить не нужно.
- **Поиск Bluetooth** — ищет ТВ поблизости по Bluetooth (классический + BLE), Samsung-устройства показываются первыми. При нажатии приложение находит этот же ТВ в Wi-Fi по имени и подключается.
  Samsung TV не принимает команды пульта по Bluetooth от сторонних приложений, поэтому управление всё равно идёт по сети — телефон и ТВ должны быть в одной Wi-Fi.
- На Android 12+ при первом поиске Bluetooth нужно разрешить «Устройства поблизости», на Android 11 и ниже — доступ к местоположению.

### Вручную по IP
- IP телевизора: Настройки ТВ → Общие → Сеть → Состояние сети → Параметры IP.
- Нажмите **OK**, на экране ТВ выберите «Разрешить». Токен сохранится, повторно подтверждать не придётся.
- Если запроса нет: Настройки → Общие → Диспетчер внешних устройств → Диспетчер подключения устройств → Уведомление о доступе → включить.

## Заметки
- Работает на Samsung Smart TV с Tizen (примерно 2016+). Старые модели (2014–2015) используют другой протокол.
- Проверка сертификата отключена, потому что у ТВ самоподписанный сертификат. Приложение подключается только к IP в локальной сети.

## Сборка APK через GitHub Actions
Запушьте проект в репозиторий → вкладка **Actions** → **Build APK** → откройте последний запуск → в разделе **Artifacts** скачайте `samsung-remote-apk`.

## Вкладка «Стиральная машина» (Samsung SmartThings)
Стиральная машина управляется через облако SmartThings (по Bluetooth/Wi-Fi напрямую Samsung не даёт ею управлять).
1. Машина должна быть добавлена в приложение SmartThings.
2. Создайте токен на https://account.smartthings.com/tokens → «Generate new token», права: Devices — List, See, Control.
3. Вставьте токен во вкладке «Стиральная машина». Он хранится только на телефоне.

Доступно: состояние (этап, оставшееся время, прогресс), старт/продолжить, пауза, стоп, вкл/выкл питания,
уведомление «Стирка закончена» (пока открыта вкладка).
Запуск с телефона возможен, только если на машине нажата кнопка «Дистанционное управление» (Smart Control).
Новые токены SmartThings действуют 24 часа — после этого приложение попросит создать новый.

## Вкладка «Колонка» (Bluetooth)
Для Bluetooth-колонки, подключённой к телефону: показывает подключённую колонку, громкость (ползунок, +/−, Mute)
и кнопки плеера (предыдущий / пауза-воспроизведение / следующий) для приложения, которое сейчас играет музыку.
Android не позволяет приложениям самим подключать Bluetooth-колонку, поэтому кнопка «Подключить колонку» открывает настройки Bluetooth.
